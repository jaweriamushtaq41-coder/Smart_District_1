# P-Task2: Student Result Processor

Students ki CSV files ka folder safely padhna. Corrupt, missing aur invalid data par crash nahi hota,
failed students flag hote hain aur clean results file ban jati hai.

- **File:** `student_result_processor.ipynb`
- **Folder `student_files/`:** notebook ki banayi hui sample CSV files aur `clean_results.csv`
- **Concepts:** `open()` + `with`, `csv` module, `try / except / else / finally`, custom exceptions, `os`
- **Chalane ke liye:** notebook kholo aur *Run All* karo
